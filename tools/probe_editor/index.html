Authoring

All coordinates are BSP units. Capture points stay fixed when moving, resizing or rotating bounds.

Rotation is X, then Y, then Z around the volume center. Higher priorities are intended to win overlapping regions. Face dragging keeps the opposite face fixed.

Save keeps a map SHA-256 fingerprint to prevent accidentally using bounds on another map revision. JSON export can be shared as reference data for automatic fitting.

Open another BSP by restarting this tool with its path and a separate output file.
