Cubemap bounds

Drag the center square to move bounds (Alt-drag when the capture point overlaps). Drag a face handle to resize along its local axis. Drag the circle to move the capture point independently. Drag the orange ring to rotate. Middle/right drag pans; wheel zooms.

Live save publishes edits when a runtime output is configured. The game keeps its previous valid reflections while changed captures are prepared.

Authoring

All coordinates are BSP units. Capture points stay fixed when moving, resizing or rotating bounds.

Rotation is X, then Y, then Z around the volume center. Higher priorities win overlapping regions. Face dragging keeps the opposite face fixed.

Save keeps a map SHA-256 fingerprint to prevent accidentally using bounds on another map revision. JSON export can be shared as reference data for automatic fitting.

Open another BSP by restarting this tool with its path and a separate output file.
